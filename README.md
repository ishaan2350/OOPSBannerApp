# OOPSBannerApp

☕ Object-Oriented Programming Learning Project built using Java.

This project demonstrates core OOP concepts and dynamic banner rendering using Java collections such as HashMap. It was developed to strengthen Java fundamentals, object-oriented design principles, and backend logic implementation skills.

---

## 🚀 Features

- Object-Oriented Programming concepts
- Dynamic banner rendering
- HashMap implementation
- Java backend logic
- Clean and modular code structure

---

## 🛠️ Tech Stack

- Java
- OOP Concepts
- Collections Framework

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/ishaan2350/OOPSBannerApp.git
```

2. Open the project in your IDE

3. Compile the Java file

```bash
javac OOPSBannerApp.java
```

4. Run the application

```bash
java OOPSBannerApp
```
